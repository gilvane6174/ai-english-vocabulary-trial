# AI活用 英単語学習キット｜GitHub無料お試し版

中学1年のUnit 1（50学習見出し）を使って、教材の形式とAIを使った英単語学習を試せる無料サンプルです。

完成版は、中学1年の基礎から大学4年・海外留学2年相当までを段階的に扱う本編10冊・12,000学習見出しに、実務英語・ビジネス英語の再編補完別冊500学習見出しを加えた構成です。

> 「12,000学習見出し」「12,500学習見出し」は、同数の異なる辞書見出し語（レマ）を意味しません。活用形・派生形・複合語・句動詞・定型表現・特定用法等を個別の学習対象として扱う場合があります。また、別冊500には本編収録語の実務用途での再編・補完が含まれます。

## この無料版に入っているもの

- `01_無料お試し版_中学1年_Unit1_50学習見出し.docx`
  - 完成版の中学1年教材と同系統の体裁で作成したUnit 1サンプル
  - No.1〜50、品詞、CEFR目安、中心義、例文、確認テスト、解答
- `02_無料版_AI学習設定文.txt`
  - 「スタート」で始める基本的な1対1英単語ドリル用の簡易設定文
- `03_無料版_セットアップ手順.md`
  - ChatGPT・Claude・Gemini等で試すための簡易手順
- `04_無料版とBOOTH完成版の違い.md`
  - 無料サンプルと完成版の収録範囲・機能差
- `LICENSE.md`
  - 無料サンプルの利用条件

## まず試す

1. `01_無料お試し版_中学1年_Unit1_50学習見出し.docx` をAIへ添付します。
2. `02_無料版_AI学習設定文.txt` の全文を、同じチャットの最初に貼り付けるか、利用できる場合はプロジェクト／カスタム指示欄へ設定します。
3. AIへ `スタート` と入力します。
4. No.1から原則7学習見出しずつ、英語→日本語、日本語→英語、短文確認の順で進めます。

AIサービスによって、ファイル添付、プロジェクト、Gem、カスタム指示等の名称や利用可否は異なります。機能がない場合は、通常の新規チャットへ教材ファイルを添付し、設定文を貼り付けて利用してください。
