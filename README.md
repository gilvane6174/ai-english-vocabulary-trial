# AI活用 英単語学習キット｜GitHub無料お試し版

中学1年相当のUnit 1・50学習見出しを使って、教材の形式とAIを活用した英単語学習を試せる無料サンプルです。完成版は、中学1年相当の基礎から高校・大学・英文学・英語学・学術分野、大学4年・海外留学2年総集編までを段階的に扱う、本編10冊・累積12,000学習見出しで構成しています。さらに、職場・会議・メール・旅行・商取引・物流・IT・契約・案内・句動詞などを実務文脈から再編・補完する、**「ビジネス英語・実務英語 再編補完別冊」500学習見出し**を付属しています。

教材は、**本編10冊＋補完別冊1冊＝全11冊**です。全11冊に掲載されている学習項目は延べ12,500学習見出しですが、別冊500には本編収録語を実務用途から再学習する項目も含まれます。

そのため、

- 12,500種類の異なる英単語
- 12,500の異なる辞書見出し語

を意味するものではありません。

本商品では、単純な異語数の多さだけではなく、**中学基礎 → 高校 → 大学 → 学術・研究 → 海外留学 → 実務英語**と、学習する領域を段階的に広げられることを重視しています。

## まず試す

### 1．教材をAIへ添付する

`01_free_sample_jhs1_unit1_50_entries.docx`を、ChatGPT・Claude・Gemini等のAIサービスへ添付します。

---

### 2．AI学習設定文を読み込ませる

`02_free_ai_learning_prompt.md`を、同じチャットへ読み込ませます。利用サービスにプロジェクト・Gem等の専用学習スペースがある場合は、教材と設定文をその中へ登録して利用することもできます。

---

### 3．「スタート」と入力する

AIへ、`スタート`と入力します。No.1から順番に、原則1学習見出しずつ学習します。

---

### 4．英語と日本語を確認する

基本的には、**英語 → 日本語**を確認し、その後、**日本語 → 英語**でも思い出せるか確認します。必要に応じて、品詞や重要語形・語法も確認します。

---

### 5．分からない部分だけAIに補足してもらう

例えば、

- この単語の短い例文を作って
- 発音を教えて
- 文法的に詳しく説明して
- この語と似た語の違いを教えて

など、必要な情報だけAIへ追加で依頼できます。AIが生成する例文・翻訳・発音補助・説明等は、教材本文に収録された情報ではなく**AI補足情報**です。

# 教材の編集・著作権への配慮

本教材は、特定の市販単語帳・参考書・辞書・Web単語リスト等の掲載順、章構成、Unit構成を再現することを目的とした教材ではありません。見出し語は、意味領域・品詞・分野等を横断する独立した構成として編集しています。日本語中心義についても、第三者辞書の長い定義文・解説文をそのまま転載する方式ではなく、一般的な語義を確認したうえで、短い学習用の中心義として整理しています。第三者教材・辞書等に掲載された固定例文も収録していません。例文が必要な場合は、AIがその場で生成するAI補足情報として扱います。

一般的な、

- 英単語そのもの
- 短い一般的語義
- 品詞
- 英文法上の事実
- 一般的な語形変化
- 公知の情報

等について、制作者が独占的な権利を主張するものではありません。

一方、本教材独自の、

- 説明文
- 教材全体の構成
- 学習項目の選択・配置
- Unit構成
- 確認テストの選択・構成
- AI学習設定文
- セットアップ資料
- ロードマップ
- 診断手順
- 進捗管理資料

等については、著作権その他の権利が認められる範囲で保護されます。第三者の著作権その他の権利を侵害しないよう編集・確認に配慮していますが、あらゆる第三者作品との非類似性や、権利侵害が一切存在しないことを保証するものではありません。

# AI利用時の注意

AIによる、

- 説明
- 翻訳
- 発音補助
- 例文
- 文法解説
- 多言語情報

等には、誤りが含まれる場合があります。AI学習設定文には、教材にない情報を教材記載情報として扱わないことや、教材本文とAI補足を区別するためのルール等を設定しています。ただし、これらの設定によってAIの誤回答・誤判定を完全に防止できるものではありません。

重要な内容については、

- 教材本文
- 信頼できる辞書
- 学校・試験実施団体等の公式資料
- 専門資料

等でも確認してください。

また、AIサービスの、

- 料金

- ファイル数上限
- ファイル容量
- 利用回数
- 対応ファイル形式
- データ取扱い
- Projects・Gems等の機能

は変更される場合があります。各サービスの最新情報を確認してください。
